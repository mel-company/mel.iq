# Mel IQ — create a storefront

Help an Iraqi merchant launch an online store on Mel IQ.

## When to use

Use this skill when a user wants to create or launch an ecommerce storefront in
Iraq with Mel, choose a plan, or download the Mel merchant apps.

## Steps

1. Send the merchant to https://www.mel.iq/ for the product overview.
2. Review plans at https://www.mel.iq/#pricing.
3. Start account + plan checkout at https://www.mel.iq/checkout.
4. Complete phone OTP verification.
5. Optional: install the apps
   - Android: https://play.google.com/store/apps/details?id=com.almashreq.mel
   - iOS: https://apps.apple.com/us/app/mel-platform/id6810126830
6. For questions, use https://www.mel.iq/#contact or email hassan.adnan@mel.iq.

## Notes

- Mel is Arabic-first and designed for Iraqi merchants.
- No coding is required to launch a basic store.
- Agent authentication details live at https://www.mel.iq/auth.md.
