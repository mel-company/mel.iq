# Mel IQ

Mel IQ (`mel.iq`) is an Iraqi ecommerce platform for creating and managing
online stores, products, orders, customers, and payments.

## For agents

- Homepage (HTML default, Markdown via `Accept: text/markdown`): https://www.mel.iq/
- API catalog: https://www.mel.iq/.well-known/api-catalog
- ARD catalog: https://www.mel.iq/.well-known/ai-catalog.json
- OpenAPI: https://www.mel.iq/docs/openapi.json
- Auth for agents: https://www.mel.iq/auth.md
- MCP server card: https://www.mel.iq/.well-known/mcp/server-card.json
- Agent skills index: https://www.mel.iq/.well-known/agent-skills/index.json
- Mobile apps:
  - Android: https://play.google.com/store/apps/details?id=com.almashreq.mel
  - iOS: https://apps.apple.com/us/app/mel-platform/id6810126830

## Product

- Launch a storefront without coding
- Manage products, inventory, orders, and customers
- Arabic-first dashboard and AI store assistant
- Pricing and checkout: https://www.mel.iq/#pricing / https://www.mel.iq/checkout
- Contact: https://www.mel.iq/#contact
